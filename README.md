# 우리의 첫 번째 페이지

해이니와 나유니의 첫 만남부터 함께한 추억을 담은 작은 기념일 웹사이트입니다.

## 열어보기

`index.html`을 브라우저에서 열면 홈 화면을 볼 수 있습니다. 홈의 버튼이나 상단 메뉴에서 `timeline.html`로 이동할 수 있습니다.
